Project Synthesis

Replicating your best employees

Formerly OrgMind · June 2026 — research started

On this page

An endpoint-native system that harvests the reasoning and workflows of a company's best employees, builds continuously learning personas, and deploys them as organization-specific agents — so institutional knowledge never walks out the door.

Research in progress. Shaped by ongoing conversations with research and product managers working on this problem at companies including Cursor and Meta. Findings and architecture are evolving as the work continues.

The Thesis

AI agents deployed in enterprises today are generic. They have no memory of how a company operates, no understanding of the judgment calls its best people make, and no way to replicate the reasoning that makes top performers effective. Prompting alone does not solve this, and RAG alone does not solve it either.

The fix is harvesting the actual workflows, reasoning patterns, and data dependencies of a company's best employees, then making that organizational intelligence executable.

Core assumptions

  • Agents working alone are generic and not tailored to how a specific organization operates.
  • No end-to-end tools exist today that generate org-level context from real employee workflow behaviour.
  • The objective is to capture workflows and map thought structure — supermemory harvesting — so LLM-powered agents can replicate a company's best performing employees and keep learning from them.
  • The supermemory is harvested directly from endpoint software logs, processed locally and in the cloud, and used to build workflow maps, reasoning traces, and deployable personas.

The Architecture

A complete pipeline from raw employee activity to executable AI personas. Four layers, each building on the one before it.

Layer 1 — Endpoint Capture Agent

The proprietary data moat. A lightweight background daemon on employee machines, event-triggered rather than continuous.

What it captures: screenshots at application-switch events and form submissions, keystroke sequences and clipboard content within active workflow windows, active window title plus application name and URL, Slack and Teams messages within five minutes of each action, file open and close events with metadata, and time on task per application segment.

What it excludes: passwords, banking fields, and HR records — redacted on device before anything leaves the machine — plus camera, microphone, anything outside work hours, and anything the employee pauses the recorder for.

Layer 2 — Supermemory Pipeline core IP

Where raw captured data becomes structured thought maps. Four stages, and this is where the research contribution lives.

Stage 1, event segmentation. Raw events are chunked into workflow episodes — a complete task from start to finish — using a fine-tuned DeBERTa or Mistral model that reads application-switch patterns and communication events as natural boundaries.

Stage 2, multimodal encoding. Each episode produces an action trace in structured JSON (what happened), screenshot embeddings via CLIP or LLaVA (what was on screen), and text context from surrounding communication (why it happened).

Stage 3, memory consolidation. The core research question: when does an episodic record graduate to semantic status, and when does a semantic fact get reinstated into working memory for a new task?

Memory tierWhat it storesStorage
EpisodicRaw episodes, timestamped, full context, never summarized at write timePostgreSQL + pgvector
SemanticAbstracted patterns from repeated episodes, extracted nightly by an LLM jobNeo4j knowledge graph
ProceduralReusable workflow templates from the highest performing episodesPostgreSQL, versioned JSON

Stage 4, persona synthesis. The three tiers combine into a Persona Card per employee or role archetype, holding role context, tool proficiency, decision patterns, communication style, the top 20 workflow templates, and the anomaly patterns that distinguish this person from peers.

Layer 3 — Agent Deployment

The synthesized persona runs as an org-specific LLM agent using hybrid retrieval. At query time it performs three-stage fusion retrieval: dense vector search over episodic memory, graph traversal over semantic memory, and a procedural lookup for a matching workflow template, merged by reciprocal rank fusion.

Claude Sonnet or Opus handles reasoning-heavy tasks; a fine-tuned Llama 3.1 8B or Mistral 7B handles high-frequency, low-stakes ones, orchestrated with LangGraph, which injects the persona's procedural memory as the starting state.

Actuation runs through MCP-native tools for Salesforce, Slack, Jira, HubSpot, and GitHub, with computer-use fallback for GUI-only legacy tools and human-in-the-loop above a configurable confidence threshold. Agent actions log back into the episodic store, so the persona improves weekly.

Layer 4 — The Data Lane

A parallel track alongside the Supermemory Pipeline, not inside it, mapping exactly which files, folders, and storage locations were touched, in what sequence, during each episode.

Three uses: employee knowledge transfer through an auto-generated KT Pack showing which files a role needs and in what order; retrospective analysis that traces which file versions actually fed a decision; and agentic real-time data fetching, where an agent queries the Data Lane index instead of guessing.

A sample fingerprint, for a content writer drafting a campaign brief:

t=0:00   Shared/Templates/Campaign_Brief_v3.docx      READ
t=0:45   Shared/Research/Competitor_Analysis_Q2.xlsx  READ
t=1:20   Personal/Drafts/Campaign_Draft_Aug.docx      READ + WRITE
t=3:10   pasted content from Competitor_Analysis_Q2.xlsx
t=4:30   Shared/Campaigns/Q3/Brief_Final_v1.docx      CREATE
t=4:35   attached Brief_Final_v1.docx to Slack

The fingerprint is always stored with its episode, never separately. A permissions mirror checks the persona's access rights before any runtime fetch, so an agent never escalates beyond what the original employee could see.

Three capture walkthroughs

How the four-layer stack behaves day by day, across three functionally distinct roles.

Maya — Marketing Researcher

Monday, 9:05: a GTM lead Slacks a request for a competitor pricing teardown by Thursday. The trigger message anchors the episode as comms context. She opens six competitor tabs, logs a read on Competitor_Tracker.xlsx, then Slacks pre-sales to ask what the prospect said about this pricing on the call — a verification habit captured only because comms are in scope. She reads the Gong transcript, copies quotes across, and drafts a doc flagging that the battle card is stale.

Over ten days, four more competitor research episodes recur. Nightly consolidation notices the shared shape and writes semantic edges: Maya always checks Gong before asserting a competitor claim, reaching 0.94 confidence by day ten; pricing strategy questions get delegated to the product marketing manager rather than answered solo.

What crystallizes: a Competitive Intelligence Request template. The Gong verification step and the delegation rule live entirely in comms and reasoning context — a click recorder alone would never surface either.

Rohan — Pre-Sales Solutions Engineer

An account executive forwards a 140-question RFP due in eight days. Rohan opens it beside Answer_Library.xlsx, a 900-row master reference the Data Lane logs every single time as the highest-centrality file in his subgraph. The core loop repeats around 40 times: read question, search library, reuse ~70%, adapt ~20%, escalate ~10%.

He Slacks the security channel to own six SOC2 and data-residency questions — an explicit escalation boundary, never answered solo. When product gives a roadmap answer, he rewrites will ship Q3 to targeted for second half before pasting. That clipboard-in versus keystroke-out diff exposes a systematic de-risking habit invisible to any process mining tool.

On day 5 the demo environment fails an hour before a call: he checks status, pings on-call, spins a backup org from snapshot, and emails a fallback plan. Low frequency, high value — tagged as an exception branch rather than averaged away.

Priya — FP&A Analyst

A deliberately different shape: no inbound message triggers this episode, so segmentation keys off a date plus tool pattern instead. Day 1 of close runs an identical export chain every month. By month three the Data Lane confidence on this chain approaches 1.0, making it a near fully automatable sequence.

When a revenue number looks off, the diagnostic order — compare to last month, check the source contract, Slack billing ops — is what gets harvested, not just the fix. And across six closes, a $40,000 dispute booked as a reserve reveals an implicit materiality threshold nobody had written down: under about $50,000, reserve and note; above it, escalate before booking.

What this adds: monthly cadence means slow episode accumulation, 12 per year rather than dozens per month. Promotion thresholds in Stage 3 must therefore be cadence-relative rather than a fixed occurrence count.

What the three establish

  • Interleaving is the default. Segmentation is really thread disentanglement, not simple time slicing.
  • The why lives in four places: trigger messages, mid-task questions to colleagues, clipboard-in versus keystroke-out deltas, and completion notes. Miss any one and the system degrades to a click log.
  • Confidence is earned per edge, not per persona, and gates autonomous action versus draft-for-review.
  • Anomaly episodes must be protected from being averaged away by routine ones.
  • Consent-driven gaps are a feature of the privacy design, not a data quality flaw.

Landscape & Next

Mimica — task mining market leader

The most important competitor to understand, and the clearest proof that the capture layer works and enterprises will pay for it. Mimica installs an endpoint recorder, observes desktop activity for one to two weeks, and produces a BPMN-style process map ranked by automation potential.

$32.2M raised total, with a $26.2M round in September 2025. Fortune 100 customers include DHL, Liberty Mutual, Merck, and Goodyear. Named a leader in task mining by Gartner and Everest Group in 2025, and actively developing an agentic layer — attempting to cross the same bridge.

The openings: the recorder only runs on Windows, an instant gap for product, design, and marketing teams on Mac. Miner-to-Mapper still requires analyst effort, so it is not a closed loop. It captures what happened, not why. Its output goes to an RPA consultant, not a continuously learning persona. And it has no Data Lane equivalent.

Viven — employee digital twins

Builds employee avatars from emails, Slack, documents, and meetings — the closest startup to the concept. The key gap: Viven tells you what people said. Synthesis tells you what they did, why they did it, and what data they needed. Communications data is descriptive; endpoint workflow data is executable.

Meta's Model Capability Initiative

In April 2026 Meta announced it is recording employee screens, clicks, and keystrokes to train AI agents for white-collar work — structurally identical to the Synthesis capture layer. This validates the approach at the highest level of technical credibility. The hostile press and employee backlash Meta received is exactly the risk Synthesis designs around.

Privacy architecture

Privacy is not a compliance checkbox, it is the primary adoption risk — and if designed correctly it becomes the primary go-to-market wedge. Meta's program failed in the press because it was imposed without consent. Synthesis is designed from day one as the opt-in, employee-controlled alternative.

All PII redaction happens on device before any data leaves the machine. Employees see exactly what is being recorded through a local real-time dashboard. They can pause recording at any time with no manager visibility into pause frequency. Data stays in the organization's own cloud tenant.

Why it compounds

Each new employee onboarded increases the fidelity of the supermemory. Cross-functional personas learn from adjacent roles — a sales manager can discover better processes from marketing workflows. The continuous learning loop feeds agent actions back into the episodic store, improving personas weekly. The longer an organization runs Synthesis, the higher the switching cost.

The workflow corpus is proprietary to each organization and not purchasable from a third party. Personas encode company-specific decision patterns that generic models cannot acquire from public data. The Data Lane creates a file-level dependency map unique to each organization's folder structure and tooling.

Why this matters

The core problem in enterprise AI is not capability, it is context. Enterprises deploy AI and watch it fail, not because the models are bad, but because the AI has no idea how the company actually operates. Generic prompting does not scale, and RAG treats all documents as equally relevant without understanding the behavioural patterns behind which documents matter and when.

Synthesis makes organizational intelligence — workflows, reasoning patterns, data dependencies, tribal knowledge — into an executable asset that AI inherits at runtime. The personas it builds preserve institutional knowledge when people leave, onboard new hires faster, let organizations scale their best performers' judgment across functions, and evolve continuously by learning from every action they take.

This is the bridge between training an AI and building an AI that does what the organization actually does.
